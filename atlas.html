Meet Sysible Atlas

A second terminal that reads your session. When a command fails, Atlas explains it and hands you the fix. Ask it a question and the answer streams in beside your shell. It runs on a local model — nothing leaves the machine. Built into SysTerm on Sysible Linux.

A real session: SysTerm split into a working shell and the Atlas companion. A mistyped apt install is caught and explained; a CrashLoopBackOff question is answered — every suggested command comes with a one-click Run in terminal.

What it does

Fewer dead ends, no copy-paste

Atlas watches the pane you're working in and turns errors and questions into answers you can run.

⚠

Catches failures

When a command exits non-zero, Atlas reads that pane's output and explains it — cause, then the exact fix — without you asking. Silence it per-shell with SYSIBLE_ATLAS_AUTO=0.

✦

Ask in the pane

Open Atlas (right-click → Open Sysible Atlas, or Alt+A) and type. The answer streams in beside your shell, with code and commands in ready-to-run blocks.

↵

Runs its own fixes

Every command Atlas suggests gets a Run in terminal button that types it straight into the pane it came from — and a Copy if you'd rather paste it yourself.

◐

Local & private

Powered by a local model via Ollama — bundled with Sysible Linux. Pick the model from the pane's selector. Nothing leaves the machine.

SysTerm — the terminal it lives in

Atlas is one pane of a fast, engineer-focused terminal: tabbed sessions, a right-click command palette, and split panes for whole-fleet work.

Tabs & sessions. Local shells, SSH targets and Kubernetes contexts as tabs — the full engineering toolchain (git, Docker, Terraform, kubectl) at the prompt.

Right-click command palette. Run Command keeps your common actions and your own saved commands one click away — next to splits, tabs, copy/paste and Open Atlas.

Split panes for fleet work. Logs, metrics, a deploy and a kubectl watch side by side — split horizontally or vertically, broadcast one command to every pane, and cycle without leaving the keyboard.

Under the hood

On-device by default

Local modelRuns against Ollama on 127.0.0.1. Defaults to a model that fits your hardware; switch it in the pane's selector.
Built into SysTermThe companion pane ships with the SysTerm terminal on Sysible Linux — no separate app, no account, no setup beyond a one-time model download.
Any distroSysTerm (and Atlas) install on Ubuntu, Fedora, Arch and openSUSE too — one line from the SysTerm repo.
