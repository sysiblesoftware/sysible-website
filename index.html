            Install in VMware Fusion (Apple Silicon & Intel)
            

              
    
                
  1. Download the .iso for your architecture (above).
    2. 
                
  2. Fusion → File → New → Install from disc or image → choose the ISO.
    3. 
                
  3. When asked for the OS, pick Linux → Debian 12.x (64-bit ARM on Apple Silicon, 64-bit on Intel).
    4. 
                
  4. Give it 4 GB+ RAM and 40 GB+ disk; enable virtualization extensions if you’ll run containers/VMs.
    5. 
                
  5. Boot it. On the Sysible boot menu pick Sysible Linux (Live) to try it, or
                  Install Sysible Linux to install to the virtual disk.
    6. 
                
  6. Live/installer default login: sysible / sysible. open-vm-tools is
                  preinstalled, so clipboard sharing and display auto-resize work out of the box.
    7. 
              

            

          


          

            Write to a USB stick & boot bare metal
            

              
    
                
  1. Download the ISO, then (optionally) verify its checksum with sha256sum -c SHA256SUMS.
    2. 
                
  2. Write it with dd, balenaEtcher, or Rufus (Windows): the image is
                  hybrid/isohybrid, so it boots on both UEFI and BIOS.
    3. 
                
  3. Boot from the stick and choose Sysible Linux (Live) or Install Sysible Linux.
    4.
