Install in VMware Fusion (Apple Silicon & Intel)
  1. Download the .iso for your architecture (above).
  2. Fusion → File → New → Install from disc or image → choose the ISO.
  3. For the OS, pick Linux → Debian 12.x (64-bit ARM on Apple Silicon, 64-bit on Intel).
  4. Give it 4 GB+ RAM and 40 GB+ disk; enable virtualization for containers/VMs.
  5. Boot it and pick Sysible Linux (Live) to try it, or Install Sysible Linux to install.
  6. Login: sysible / sysible. open-vm-tools is preinstalled, so clipboard sharing and display resize work out of the box.
Write to a USB stick & boot bare metal
  1. Download the ISO, then (optionally) verify it with sha256sum -c SHA256SUMS.
  2. Write it with dd, balenaEtcher or Rufus — the image is hybrid/isohybrid, so it boots UEFI and BIOS.
  3. Boot from the stick and choose Sysible Linux (Live) or Install Sysible Linux.
